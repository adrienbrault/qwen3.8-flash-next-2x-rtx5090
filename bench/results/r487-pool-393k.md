R487 compared the served configuration against C = split [30, 31], chunk 2048, pool 393,216 (+9 %), 3.05bpw pack. R488 re-measured with [`bench/multiprompt.py`](../multiprompt.py): 12 prompts per kind, temperature 0.6, top_p 0.95, top_k 20, per-prompt seeds, 1,024 forced tokens, arms S0 / C0 / S1 / C1 (results `2026-09-18-r488-multiprompt`, raw records [`2026-09-18-r488-multiprompt/`](2026-09-18-r488-multiprompt/)). Paired by seed, C against S: code c1 +1.4 % (median +0.2 %), code c4 0.0 %, prose c1 −0.7 %, prose c4 −2.7 %, all inside the per-prompt spread (136–219 t/s at c1 within one arm).

The −17 % from R487 was the single greedy code text: the moved layer changes rounding, the greedy text changes, and its draft acceptance with it. Since R488 any change that alters numerics is judged on the multi-prompt probe. The same probe shows sampled c1 at about 162–168 t/s for both kinds, against 212–216 for the greedy code prompt.
